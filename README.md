# My Survey Basket API

A Web API for creating surveys, collecting votes, and viewing poll results.

## Features

- Create, update, publish, and delete polls
- Add questions and answer choices to each poll
- Let members view available polls and submit votes
- Prevent duplicate voting on the same poll
- View poll results, including votes by day and by question
- Register users, confirm email addresses, log in, and reset passwords
- Use JWT access tokens and refresh tokens for secure sign-in
- Manage user profiles and change passwords
- Protect actions with roles and custom permissions
- Send email notifications for new polls
- Run background jobs with Hangfire
- Explore and test the API with Swagger
